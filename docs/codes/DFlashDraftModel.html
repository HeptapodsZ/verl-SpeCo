1. 先给结论

它是什么

一个接收 target 多层 hidden states 作为 context，并对若干 draft block 产生 hidden representation 的轻量 Transformer。

它输出什么

DFlashDraftModel.forward() 只返回 draft hidden states；它不负责 target-head logits，也不直接计算 CE loss。

训练入口在哪里

外层 DFlashTrainingModel.forward() 负责 context 投影、anchor/noise/mask、labels 和 loss，并调用裸模型。

最重要的边界 DFlashDraftModel 不是完整的训练 loss module。实际训练对象是 DFlashTrainingModel(draft_model=DFlashDraftModel)；frozen target lm_head 由 DFlashTrainerBackend 单独持有。

extract_context_feature() 要求输入列表长度严格等于 C。先沿最后一维拼接，再通过 fc + RMSNorm 压缩到 drafter hidden size。

C × [B, Lc, Ht]
  → concat
[B, Lc, C×Ht]
  → fc + hidden_norm
[B, Lc, Hd]

MLP 使用 SiLU(gate_proj(x)) * up_proj(x)，再经 down_proj 返回 hidden size。

4. Forward 输入输出契约

参数典型形状作用训练路径是否使用
draft_input_ids [B, Ld] 未提供 noise embedding 时，用它查询 drafter embedding。 否；训练传 None
context_feature [B, Lc, Hd] 由 target 多层 hidden states 投影得到，作为 attention 的 context KV 来源。 是
draft_position_ids [B, Ld] draft query 和 draft KV 的 RoPE 位置。 是
context_position_ids [B, Lc] target context KV 的 RoPE 位置。 是
block_mask FlexAttention BlockMask CUDA 路径的结构化可见性约束。 CUDA 使用
dense_attention_mask 可广播到 [B, Nq, Ld, Lc+Ld] 非 CUDA 路径使用的 dense mask。 CPU/NPU fallback 使用
noise_embedding [B, Ld, Hd] 由真实 anchor token 与 mask tokens 组成的训练输入 embedding。 是
返回值 [B, Ld, Hd] final RMSNorm 后的 draft hidden states。 交给外层 target head 计算 logits
注意：Lc 与 Ld 不同 Lc 是 target context 长度；训练时 Ld = A × block_size，其中 A 是采样 anchor 数。示例配置中最多为 64 × 16 = 1024 个 draft positions。

5. Forward 完整链路

① Target context 5 层 target hidden states 拼接，经 fc + RMSNorm 得到 context feature。
② Draft input 训练路径使用 anchor token + mask tokens 组成的 noise embedding。
③ Decoder layers draft 作为 Query；context + draft 共同作为 KV；执行 masked GQA。
④ Final norm 所有 decoder layer 后执行最终 RMSNorm。
⑤ 外部 head 裸模型之外用 frozen target lm_head 投影 logits，再计算 restricted CE。

6. Dual-source Attention 细化

DFlashAttention 的关键不是普通 self-attention，而是：

Query
只来自当前 draft hidden。
Key
K = concat(K_context, K_draft)。
Value
V = concat(V_context, V_draft)。
Mask
由 backend 构造，约束每个 draft block 能看到的 target prefix 与 block 内位置。
Evidence G：Query 与双来源 KV verl_speco/models/dflash/modeling_dflash.py:158-176 
q = self.q_proj(draft_hidden).view(...)
q = self.q_norm(q).transpose(1, 2)

k_ctx = self.k_proj(context_hidden)
v_ctx = self.v_proj(context_hidden)
k_draft = self.k_proj(draft_hidden)
v_draft = self.v_proj(draft_hidden)
k = torch.cat([k_ctx, k_draft], dim=1)
v = torch.cat([v_ctx, v_draft], dim=1)

6.1 RoPE 位置处理

Query 只使用 draft_position_ids；Key 同时包含 context 和 draft，因此使用两者拼接后的 full_position_ids。这保证 target context 与 draft positions 位于同一位置坐标系。

full_position_ids = torch.cat(
    [context_position_ids, draft_position_ids], dim=1
)
...
q = apply_rope(q, draft_position_ids)
k = apply_rope(k, full_position_ids)

实际实现证据：verl_speco/models/dflash/modeling_dflash.py:178-189

7. 训练路径张量形状追踪

阶段张量形状生产者 → 消费者
Backend 输入 hidden_states [B, Lc, C×Ht] DrafterBaseTrainer → DFlashTrainerBackend
按 layer 拆分 hidden_states_list C × [B, Lc, Ht] DFlashTrainerBackend → DFlashTrainingModel
Context projection context_feature [B, Lc, Hd] DFlashDraftModel.extract_context_feature → TrainingModel
Anchor sampling anchor_positions [B, A] DFlashTrainingModel 内部
Draft/noise input noise_embedding [B, A×K, Hd] DFlashTrainingModel → DFlashDraftModel
Attention Q q [B, Nq, A×K, Dh] q_proj → attention kernel
Attention K/V k, v [B, Nkv, Lc+A×K, Dh] context+draft projection → attention kernel
裸模型输出 draft_hidden [B, A×K, Hd] DFlashDraftModel → DFlashTrainingModel
Active hidden active_hidden [Tactive, Hd] loss mask 选择 → frozen target head
Restricted logits active_logits [Tactive, Vrestricted] F.linear → cross_entropy

K 是 block size，示例为 16；A 最多 64；Lc 在预处理后最多 512； Tactive 由有效 anchor、block 内有效位置和 response loss mask 共同决定。

设备与梯度边界 Target hidden states 在 old-logprob 路径已经 detach、复制到 CPU，再送到 drafter worker；训练 batch 随后搬到 drafter GPU。因而该 forward/backward 图只连接 drafter 参数，不会反向传播回 Qwen3 actor。target lm_head 和 drafter embedding 同样被冻结。

9. What / How / Why

What

将 target model 已计算出的多层上下文表示压缩为 context memory，并从带噪 draft blocks 产生可由 target head 解码的 hidden states。

How

多层 hidden concat/project；draft token 做 Query；target context 与 draft token 联合作为 KV；mask 控制每个 block 的合法信息流。

Why

避免重复运行完整 target Transformer，同时让 drafter 使用 target 的上下文表征，并通过共享/同步的 target head 学习 token prediction。

必须保持的源码不变量

  • len(hidden_states_list) == num_context_layers。
  • 每层 target hidden 的最后一维必须等于 target_hidden_size。
  • target_layer_ids 数量必须等于 num_context_layers。
  • block_mask 与 dense_attention_mask 不能同时传入 attention。
  • 裸模型输出维度必须与 target lm_head 输入 hidden size兼容。
  • 训练路径中 target head 和 embedding 不应接收梯度。
